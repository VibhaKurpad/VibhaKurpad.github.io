# Changelog

## 1.0.0 · October 26, 2026

First release of Craft Happens.

- Crochet, knitting, and hand embroidery with three skill levels and 18 projects.
- One- and two-week plans tailored to 15–60 minutes per making day, with rest days.
- Supply checklists and non-affiliate shopping links.
- Curated video lessons and clearly labeled project walkthrough searches.
- Three AI-generated progress pictures for each project, with an enlarged view.
- Browser-local saved progress and a printable plan.
- Pastel styling, subtle background captions, and responsive layouts.
- GitHub Pages deployment, CodeQL scanning, dependency audits, and Dependabot updates.

Project pictures illustrate the stages rather than exact tutorial outcomes. Tutorial popularity labels are research snapshots, not live rankings. No backend, accounts, or API keys are required.
